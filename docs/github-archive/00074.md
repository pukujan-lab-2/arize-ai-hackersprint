Alex wants agents to stop writing modules that a maintained package already covers. His rule: never hand-write custom code when mature OSS or an existing tool plus thin glue code can do the job. Manual coding is allowed only for confirmed debugging or fixing logic pipelines.

## What changed

- AGENTS.md has a new short section, "Reuse before you write", placed after "Where things go". The CGM boot block and the OIO markers are untouched.
- contracts/agents/coding-agent.json gets two rules: the policy itself, and that a PR adding a new custom module names the OSS options it considered. The pipeline contracts (planner, retriever, answer, safeguard) describe runtime steps that never write code, so they stay as they are.
- .github/pull_request_template.md is new, with an "OSS considered" line. repo.manifest.json mentions it in the .github/ entry.
