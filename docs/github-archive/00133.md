# Issue #133: Map: show the pipeline while a run works, and name the path it actually takes

- State: open
- Opened by Pukujan on 2026-10-19
- Original: https://github.com/Pukujan-lab/arize-ai-hackersprint/issues/133

The run's work is invisible on the map, and the progress text claims paths the run does not take. Evidence is in `docs/issues/2026-10-19-map-voice-retrieval-regressions.md` (sections C13–C14).

**Observed on the deployed build `f7e87bf`:**
- `/map` shows no planner, retriever, graph, writer or citation check while a question runs. The only progress surface is the `Run progress` block on Home.
- Run `145112-49e18a` reports "Octo hybrid passage search", "1-hop SurrealDB traversal" and "citation-weighted PageRank", while the same event carries `"backend": "networkx"`. The search is one full-text query, the graph is local, and the ranking is in-degree — none of the three claims is true.

**Must instead:** the map shows each pipeline stage as it starts and finishes, a cached replay is marked as a replay, and every stage message names the path actually used.

Acceptance tests and spec outcomes (`O91` onward) land before any application code changes.
