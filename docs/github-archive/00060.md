Adds `close-linked-issues.yml` for the UI cleanup work (#58). No app code changes.

When a PR merges into main, the workflow closes any issue the PR body names with Closes, Fixes or Resolves #N that is still open, ticks it off on the UI cleanup tracker #58, and closes the tracker once every issue on it is closed. Merges made by the auto-merge token don't trigger other workflows, so it also runs every 30 minutes, on push to main and by hand, sweeping PRs merged in the last three days. That sweep should close #33 and #44, which #59 named but left open.

Installing Chromium in CI is split out: with it, main currently fails four overflow checks on Linux (/dashboard and /guide at 1024 px, /observability at 768 and 1024 px). That lands together with an ABA-built fix so the gate doesn't block every PR.
