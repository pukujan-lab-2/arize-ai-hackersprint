The `gates` frontend build has failed with `vite: not found` since 2026-10-20. Two changes that day caused it:

- A root `pnpm-workspace.yaml` (`packages: ["."]`). When `pnpm install` runs in `web/`, it now treats the repo root as the workspace and installs only the root package (25 packages), so web's own dependencies, vite included, never get installed.
- `maplibre-gl` was added to `web/package.json` without updating `web/pnpm-lock.yaml`, so `--frozen-lockfile` would fail even after the first problem is fixed.

The fix:

- The CI frontend step now runs `pnpm install --frozen-lockfile --ignore-workspace`, the same flag the root `package.json` scripts already use.
- `web/pnpm-lock.yaml` now includes `maplibre-gl`.

`deploy/deploy.sh` builds from a `git archive` of `web/` in a temp dir, outside the workspace, so the lockfile update alone fixes it.

Checked locally: a clean frozen install plus `pnpm build` in `web/` succeeds.
