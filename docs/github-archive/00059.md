Refines the demo's first screen and makes every page work from 360 to 1440 px. Layout and dark glass style unchanged.

**First screen (/)**
- A dismissible "Start here: ask a legal question, or try an example." line with numbered steps: 1 Ask · 2 Read the cited memo · 3 Take the map tour. Dismissal is saved in localStorage (`precedent.firstScreenDismissed`).
- The question box shows a placeholder (`e.g. Automobile exception: …`) instead of prefilled text. An empty Ask runs that example. In follow-up mode, an empty Ask shows an inline hint instead of doing nothing (#44).
- Ask gets a gentle pulse plus the `first-visit` class for first-time visitors, has an aria-label and tooltip, and respects reduced motion.
- New Answer empty state: "Your cited memo will appear here", how it works, and a **Try an example** button.
- The mic is labeled "Ask by voice" (aria-label, title, visible pill on desktop). Tour controls have tooltips, a labeled `#tour-controls` toolbar and `data-tour=prev|voice|play|next`.
- Adds the missing `static/theme/precedent-theme.css` and favicon (#33).

**Responsive (all pages: /, /map, /dashboard, /slides, /guide, /observability)**
- New `static/responsive.css`, which navbar.js injects on every page after its own styles.
- No horizontal scroll at 360/390/768/1024/1440. Fixes: wrapping navs, the map search form on its own row, guide step and partner rows, scrollable observability table.
- 44 px tap targets on phones, tablets and touch screens.
- On phones the input sits on its own row and Ask/Examples stack below it.
- The floating mic shrinks to 56 px in the corner and the page reserves space under it, so it no longer covers Ask or content.
- Cache-busting bumped to `?v=ux1`.

**Tests (written first; 42 failed before the change, 61 pass after)**
- `tests/test_first_screen.py`: cue, steps, placeholder, highlighted Ask, empty state, aria-labels, persistent dismissal, empty-Ask hint.
- `tests/test_responsive.py`: overflow at 5 widths × 6 pages, tap targets at 360/390/768, stacked input on phones, mic not covering Ask.
- `tests/uiserve.py` serves static/ on the app's routes with /api stubbed. Tests skip if Chromium isn't installed (as in CI).

Not done: the slides deck is a fixed 16:9 presentation scaled to fit, so links inside slides are excluded from the tap-target check.
