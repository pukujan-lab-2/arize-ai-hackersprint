Fixes voice-over lines being cut off when the next clip loads (summary → tour hand-off, between tour stops).

- audio.js: one-at-a-time is now a **queue**: a new clip waits until the current one ends; only Stop / Mute / new question / skipping a step interrupts (epoch token drops queued + stale clips). Browser speech also waits its turn.
- Tour advances on the narration's `ended` (duration-based safety timer); next stop's clip is **prefetched** (download only) while the current one plays.
- Auto summary queues behind any playing tour line and goes before the tour's first voice-over; tour stop 1 is prefetched during the summary.
- Cache-bust ?v=aq3.

Tests: tests/test_audio_queue.py (offline queue tests + live full flow: ask → summary → 5 clips, every clip played to its full duration, no overlaps).
