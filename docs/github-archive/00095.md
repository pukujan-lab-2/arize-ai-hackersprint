# V2 tour narration flow and skip-to-stop

Queued follow-up to #94 (filed after Alex review of live v2). ABA-only, tests-first. Do not start until #94 is merged/deployed.

## Requests from Alex
1. Tour bar speaker icon: the speaker/voice icon is back in the tour controls (prev / speaker / Pause / next) — remove it / do not reintroduce it. Keep prev / Pause / next only (plus the existing Tour entry point pill).
2. Narration flow: the spoken summary should start first ("instead of just the tour") — summary narration plays/starts, then the tour follows, rather than jumping straight into tour voice. Preserve the prior rule: tour autoplays after the memo. Clarified flow: summary audio starts first, tour is the continuation, never tour-voice-first.
3. Tour voice skip: user must be able to skip the tour voice/narration to the part (stop) they are on — e.g. tapping a stop/dot/pin or next/prev jumps narration to that stop (seek/skip-to-current), not force listening from the start.
