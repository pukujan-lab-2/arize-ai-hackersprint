## Summary

PR #80 (actions/checkout 4→7) and #90 (actions/setup-python 5→7) both failed `gates` with:

```
OIO install refused: managed file changed since OIO installed it: .github/workflows/issue-triage.yml
```

OIO records a sha256 for each managed file in `.oio/install-manifest.json` and the installer refuses drift. Dependabot bumped those two actions inside `issue-triage.yml`, which OIO owns, so neither PR can ever pass as-is.

This ignores both actions in the `github-actions` update config. Other action bumps (#77, #78, #79) merged fine because those actions do not appear in the managed workflow.

Supersedes #80 and #90; both are closed in favour of this config change.
