# Issue #129: v3: reading and map regressions — memo, sources, drawer, 3D map, jurisdiction zoom, map key, narration (O65–O72)

- State: open
- Opened by Pukujan on 2026-10-19
- Original: https://github.com/Pukujan-lab/arize-ai-hackersprint/issues/129

## Summary

The v3 rebuild shipped every page, but the live build regressed the reading experience: the memo renders as raw Markdown, its citations cannot be checked, the header is crowded with buttons that never close, the map is flat with pins drawn on top, zoom is a free scale factor rather than a jurisdiction, the legend and attribution sit over the drawing, and live narration is gone. This issue tracks the repair. The full observations, evidence and required behaviour are in `docs/issues/2026-10-19-ui-regressions.md`; the binding outcomes are O65–O72 in `docs/specs/2026-10-18-frontend-v3.md`.

## Observed facts

- The memo element is a single paragraph holding the Markdown source (`**Short answer:**`, `### Key authorities`); the page has no heading, list or bold element in the memo.
- The memo section contains zero links. A `Sources` button sits in a row with six other controls.
- After a run, seven buttons share the memo header, none of which closes itself.
- The map canvas exposes a 2D context, not WebGL.
- Zoom changes a scale factor only; clicking a county shows a tooltip, and there is no county, court, state or national level.
- The legend, a summary line, the basemap switch and the attribution are laid over the map at all times.
- `Listen` starts a voice clip, but the tour shows a static block of text rather than a transcript that advances with the audio.

## Interpretation

*Inferred:* the rebuild replaced the retired perspective scene and the retired reading renderer with simpler equivalents, and the gates did not cover either. The outcome text is now explicit, so the repair can be checked mechanically.

## Acceptance

The gates in `tests/test_frontend_v3_reading.py` (O65, O66, O67, O71) and `tests/test_frontend_v3_map_levels.py` (O68, O69, O70, O72) pass against a fresh build; the existing suites stay green; O47–O51 continue to hold at 360, 390, 768, 1024 and 1440 wide.

## Boundaries

This issue does not restyle the app, change the observability dashboard or the slides deck, or reintroduce any retired frontend. There is no fallback path to an older version.
