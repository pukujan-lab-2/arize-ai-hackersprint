Docs only. Updates the access section now that all three scorers work.

- **Octo vault key is a grant, not an API key.** `GET /api/vault/open` lists the cabinet, `POST /api/vault/open/lease` with an `itemId` returns a short-lived `octo_tmp_` key and a proxy, and calls go to `/api/vault/proxy` with `x-octo-target` naming the vendor. That is how JEV is reached; a raw OpenRouter bearer is rejected.
- **GLiNER** runs on the Windows host against the torch already installed there; the pinned checkpoint loads in ~40 s and returns the `{label, confidence}` shape the harness expects.
- **MiniCheck** is reachable through `engine.check`.

Verified end to end: a JEV claim-support decision returned `supported` at 0.99 for 365 input tokens and $0.0000153.
