# Issue #131: Map: county borders, court names and dates, real placement, links and motion

- State: open
- Opened by Pukujan on 2026-10-19
- Original: https://github.com/Pukujan-lab/arize-ai-hackersprint/issues/131

The map still falls short of v1 in six ways, recorded with evidence in `docs/issues/2026-10-19-map-voice-retrieval-regressions.md` (sections A1–A7).

**Observed on the deployed build `f7e87bf`:**
- County outlines are not drawn in the WebGL scene. The scene builder emits triangle fills only; the `countyLine` colour is used only by the 2D fallback.
- Court-level labels show the case title alone. The owner asked for the court and the year on the map.
- Every case reports `"court": "Colorado state court"` even though its passage names "Supreme Court of Colorado" or "Colorado Court of Appeals".
- Eight authorities collapse into two pins (Capitol and Denver). A live probe of run `145112-49e18a` returned `0 counties linked · 1 jurisdictions · 0 links`, with county and court labels `None`.
- Four citation edges exist but zero arcs are drawn, because the edges name authorities that were cut from the final eight.
- The only animation is a camera tween. There is no pin arrival, halo, active-stop highlight or link draw-on.
- The map subtitle is a count line, not the run's short answer.

**Must instead:** every county has an outline; court labels name the deciding court and year; an authority is placed where the record places it; every drawn link joins two shown authorities; a run animates in and the active stop is marked; the map shows the short answer as its summary.

Acceptance tests and spec outcomes (`O80` onward) land before any application code changes.
