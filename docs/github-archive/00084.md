# PR #84: One collapsible sidebar for navigation on every page

**Problem.** Navigation was split between a crowded top navbar and a sidebar that also held activity, sources, run history, voice and partner panels, so it was hard to find your way around and the main column felt cramped.

**What changes (built by ABA, app-builder-automation).**
- One collapsible sidebar (`#sidebar`, toggled by `#sidebar-toggle` in the top bar) replaces the navbar menu on every page.
- The sidebar holds navigation links only: Home, Map, Run history, Dashboard, Observability, Guide, Slides. The current page is marked.
- The panels that used to move into the sidebar stay in the main column. Example chips stay next to the ask box.
- On phones it is a closed drawer that Esc closes. On desktop it remembers whether it was open or closed.

**How to verify.** Test first: tests/test_sidebar_nav.py (top bar contents, links and current page, phone drawer and Esc, remembered state, and a new navigation-links-only check) failed on main and passes here, together with tests/test_responsive.py. On the live site, open any page at 1440 and 390 px and use the toggle.

**Unchanged.** No server, API or dependency changes.
