## Summary

`GET /map` no longer renders the old single-page map app. It serves `static/v2.html` — the same file as `/` — with the map pane preselected, so the map route and the demo route are one experience instead of two divergent frontends.

- `static/v2.js`: adds the `?run=<id>` deep link so a link to a finished run on `/map` still opens that run's memo and map.
