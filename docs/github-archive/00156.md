`python3 acs/claim.py log` with no topic passed `None` into `board.log`, which called `topic.lower()` and raised `AttributeError: 'NoneType' object has no attribute 'lower'`. Hit while filing an issue log for HACK-04.

Two changes:

- `acs/claim.py` checks for a topic before calling `board.log` and exits 2 with a usage line. A log without a title still works: the title falls back to the topic, which is what `a.title or a.task` was trying to do.
- `acs/board.py` raises `ValueError("log needs a topic")` instead of an `AttributeError`, so any other caller gets the same clear failure.

`acs/claim.py` parses arguments at import time, so `tests/test_acs_claim.py` drives it as a subprocess with `ACS_ROOT` pointed at a temporary directory. That keeps the test off the real board and lets it assert the error path writes no record.

Verification: `ruff check` and `ruff format --check` pass; the three new tests pass.
