# V2 mobile single-pane: Answer vs Map toggle, panels reuse the same pane

Queued follow-up to #94 (filed after Alex review of live v2 on a small screen: "current mobile looks horrible; both answer and map open at once"). ABA-only, tests-first. Do not start until #94 is merged/deployed.

## Change (small screens, e.g. <=899px as in v2.css)
- Do NOT keep both the answer panel and the map open simultaneously on mobile.
- Buttons/tabs switch ONE content pane: Answer/Summary vs Map. The selected one occupies the full available screen height vertically (full-height pane) between the header/rail area and the sticky bottom chat input, which stays.
- Sources / Legend / Follow-ups buttons open their panels FROM THE TOP and replace/reuse the answer pane area (the short-answer card area), not as bottom sheets and not stacked over/below the content. I.e. mobile has ONE content pane; Answer / Map / Sources / Legend / Follow-ups each occupy that same full-height pane when selected; close returns to Answer.
- Tour remains an existing button entry point (its in-map controls unchanged by this issue).
- Desktop layout unchanged: Split view (map left, answer column right) as now.
