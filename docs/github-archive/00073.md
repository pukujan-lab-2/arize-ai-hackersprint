### Affected App, Adopter, Users, or Systems

Every coding agent working in this repo, and the people reviewing their PRs.

### Observed Consequence and Workaround

Observed: AGENTS.md and contracts/agents/coding-agent.json say where code goes and how it ships, but nothing tells an agent to reach for an existing library or tool before writing its own. The repo has no PR template, so a PR that adds a new module never has to say what else was looked at.
Expected: Alex's rule is written down where agents read it at boot: "Never hand-write custom code when mature OSS or an existing tool plus thin glue code can do the job. Manual coding is allowed only for confirmed debugging or fixing logic pipelines." A PR that adds a new custom module names the OSS options it considered.
Workaround: Alex repeats the rule by hand in each task.
