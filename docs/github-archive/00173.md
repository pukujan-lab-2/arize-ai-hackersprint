# PR #173: Survey the data sources past Colorado and the 137 existing components

Research doc, no code. Two parts.

**Part 1 — where the data comes from.** Grounded in the actual documentation, not recall:

- **CourtListener bulk** — S3, quarterly PostgreSQL `COPY` dumps, **Public Domain Mark**, 9M+ opinions, 2,000+ courts, and a **resolved citation map** (`citing_opinion_id, cited_opinion_id, depth`). Crucially it also ships `courts.appeals_to`, which is what makes *binding* authority computable — the thing our hand-built graph can never do.
- **GovInfo** — US Code, eCFR, CFR annual 1996–, Federal Register 2000–, Statutes at Large 1789–, as **USLM XML**, plus an MCP server in public preview.
- **CAP** — `case.law/bulk/` now 404s; reachable through CourtListener's `filepath_pdf_harvard` and Harvard LIL's `cold-cases`.
- **JusticeDAO** — 322 datasets, **no models**, municipal code with `authorizing_for_publication: false`. Architecture reference only.

**Honest limit:** federal and state *appellate* law is a solved ingestion problem. **County and municipal law is not** — no free authoritative source, and several publishers assert rights over annotations.

**Part 2 — 137 options** across corpora, statutes, parsing, chunking, lexical/dense retrieval, fusion, reranking, graph retrieval, query understanding, grounding, evaluation, serving and legal ranking signals. Each has a verdict: use / try / skip / gap.

**Three conclusions:** the citation graph is solved and we were rebuilding it badly; the expansion is ingestion for appellate law and unsolved for county law; and the differentiator is binding-authority weighting plus a citator — not the retriever, which is commodity. A production legal product without a citator is selling something it cannot back.
