On the live site a correctly cited answer failed the citation check: the model wrote `... absent a recognized exception. [1][4]`, the checker split at every full stop, `[1][4]` became a fragment of its own, and the sentence before it was counted as an uncited claim (`unsupported_claims` 2, `pass: false`), so the page said 'Citation check failed' with no invalid references and no unknown authorities.

- `app/agents.py`: new `split_sentences` keeps a citation group that follows a full stop on the sentence before it; `uncited_claims` uses it; `support_claims` (the claim-support builder) uses the same split. A sentence with no citation is still flagged.
- `tests/test_safeguard_sentences.py` (written first, 5 tests): citation after the stop, before the stop, a real uncited sentence still flagged, a lone citation group is never a sentence, and the support claim takes the whole sentence.

This does not change what the check demands (every long sentence needs a retrieved citation, no invented authorities); it only stops counting formatting as missing sources.
