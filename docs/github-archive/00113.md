## What changed
- **Listen** sits on the memo head, never in the tour bar. It replays the stored summary through the same starter as the first read: summary clip first, then the tour from stop 1. The question is never re-asked.
- **Tour controls** stack vertically (prev / play / next) at the middle of the map's right edge instead of a bottom-center row.
- **Narration order** is enforced: the summary clip is spoken before any tour clip is requested.
- **Stopping is the reader's word**: a stop made by the app itself (speaking the summary, a reset) or a soft stop (stop advancing, let the line finish) no longer counts as the reader stopping the walk. A genuine stop (Escape, drag, wheel, Tour pill) still keeps a summary that is still playing from restarting the tour behind it.
- **Pin taps** open the slim preview; a tap that lands on a pin chip's point is treated as that pin's tap, so the preview opens at any width while the camera settles.
