## Summary

The v2 composer now knows which end of a thread it is at.

- **Ask → Follow-up.** `#go` reads `Ask` until a memo has rendered, then `Follow-up`. The label decides the thread, not the phrasing: with a memo on screen every submit carries `prev_run_id` of the last run, so "Colorado water rights" after an answer still continues that run instead of starting a new one. The old `isFollow()` regex is gone.
- **New question.** `#new-question` appears directly above the input with the first answer. Pressing it drops `prev_run_id`, clears the memo, the sources, the follow-ups, the run info and the Listen bar, stops the tour and any audio, closes the sheets and the pin strip, and puts `Ask` back. It is created and removed by `v2.js`, so a fresh page has no such button in the DOM.
- **Pill slider.** `.v2-pills` is one horizontal track (`flex-wrap: nowrap`, `overflow-x: auto`, hidden scrollbar) that never wraps to a second row; the Tour pill is gone, leaving exactly Sources, Follow-ups, Legend. `:focus-visible` rings added to pills and the new button.
- **Sent-question strip.** The input clears on submit and the question that was sent appears in `#sent-question` at the top of the map: one transparent line (`pointer-events: none`) that fades out after ~4 s and returns with the next question. Opening `#pin-preview` hides it so the source strip owns the top edge; `prefers-reduced-motion: reduce` makes it appear and leave with no transition.
- Passage scoring now uses the submitted question (`lastQuestion`) instead of `#q`, which is empty by the time the memo renders.
