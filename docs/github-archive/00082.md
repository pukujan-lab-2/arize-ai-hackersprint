### Observed Consequence and Workaround

Observed in the gates run for #76 (e813b12):
1. The step meant to warn about known vulnerabilities in the Python 3.9 pins the Pro runs printed nothing. pip-audit reads requirements.txt with the runner's Python 3.11 markers, so it skips the 3.9 lines. Run on Python 3.9, it finds advisories in starlette 0.49.3, python-multipart 0.0.20, urllib3 2.6.3, requests 2.32.5, anyio 4.12.1 and python-dotenv 1.2.1.
2. The SDK warning fired on tests/fixtures/pr_policy_cases.json, a test fixture that holds a provider URL on purpose. Paths under tests/ are not treated as tests, and non-code files are scanned.
Expected: CI warns about the 3.9 pins, and the SDK warning only looks at code files outside tests/.
Workaround: run pip-audit on Python 3.9 by hand, and ignore the fixture warning.
