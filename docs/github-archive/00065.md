The tour now starts at stop 1 right after the memo and walks the sources in [n] order.

**Why it skipped stop 1**
- On the home page, `render()` showed the run and started the memo but never set `window.__early`. The activity feed then replayed the `ranked` event and called `Docs3D.show()` a second time with the ranked-event citations (passages cut at 600 characters, no documents). That also re-armed `show()`'s autostart timer, so a silent caption tour started while the memo was still playing.
- `Docs3D.order()` kept only sources with a complete "holding" sentence (or a cited-by link) and sorted those first. With the cut passages, [1], [3] and [7] dropped out, so when the memo ended `tour(0)` narrated [2].

**What changed (built by ABA, iterate mode, no hand edits to static/)**
- `static/index.html`: `render()` marks the run as shown, so the feed doesn't show it again.
- `static/map3d.js`: `show()`'s autostart does nothing while the voice is held or a summary is pending; the pages still call `Docs3D.tour(0)` when the memo ends. `order()` keeps every numbered source that has something to say (holding, cited-by line or memo line) and sorts by [n] only.
- `?v=ts1` on the pages that load the changed files. ABA also added `.dyad/` to `.gitignore`.
