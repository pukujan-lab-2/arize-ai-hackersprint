## What changed

**1. Pins were in the wrong place.** The court coordinates were fine. I checked all 64 Colorado county seats with shapely point-in-polygon against the Census county GeoJSON the map already loads, and every seat falls inside its county. The real bug was in how pins were drawn. Each hand-made marker element had a Tailwind `relative` class, which overrode MapLibre's `position:absolute` on `.maplibregl-marker`, so the pins drifted away from their coordinates. Pins are now react-map-gl `<Marker>`s, and the library owns the positioned wrapper. A second bug: MapLibre 6 ships its tile worker as a separate module. It was never emitted or registered, so no tiles ever drew ("Worker failed to load"). It is now registered with `setWorkerUrl` and a Vite `?url` import.

**2. Prebuilt map library.** Added `react-map-gl@8.1.3` (MIT) on top of `maplibre-gl@6.15.0` (BSD-3-Clause). The basemap is the OpenFreeMap `positron` style: OSM vector tiles, no API key. The pale grey look of the old muted raster is kept. Versions are pinned exactly, including in the root `package.json`. Added `@types/geojson@7946.0.16` so `tsc` passes. The web lockfile now includes maplibre-gl, which fixes `pnpm install --frozen-lockfile`; it was failing on main.

**3. The tour flies with the voice.** `tourPlan` now records a cue at each `[n]` citation mark in the summary and memo sections: the character offset and the cited pin. It also strips the marks so the voice doesn't read them. `useTour` exposes `focus`, which is set at each step boundary and updated by the speech engine's word-boundary events (`heard`) as the voice reaches each cue. The map calls `flyTo` on every focus change. The question and the summary open on an overview of every authority. The memo dropdowns, drawer and TourBar work as before.

Also fixed the 4 lint errors that were already on main (no-useless-escape, empty interfaces, `require` in the tailwind config).

## OSS considered
- `react-map-gl` (vis.gl): used because it gives declarative Source/Layer/Marker and replaces the hand-written marker and layer code.
- OpenFreeMap: used because it needs no key, unlike MapTiler or Stadia.
- `leaflet`/`react-leaflet`: not used because it has no vector tiles and no smooth flyTo arcs comparable to MapLibre's.
