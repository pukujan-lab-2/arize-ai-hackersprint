# Issue #6: CI/CD pipeline, auto-merge, ACS hot-loader, PDD hardening

- State: open
- Opened by Pukujan on 2026-10-17
- Original: https://github.com/Pukujan-lab/arize-ai-hackersprint/issues/6

## Plan
1. **CI** `.github/workflows/ci.yml` — on pull_request + push to main: Python 3.11, `pip install -r requirements.txt`, ruff (non-blocking), pytest. Tests needing data (`data/nodes.jsonl`), network, a live server, or secrets are skipped/marked so CI is deterministic. Required job: **`gates`**.
2. **Auto-merge** — repo: auto-merge + squash only + delete branch on merge. Ruleset/protection on `main` requiring `gates`, 0 approvals, admin bypass. `.github/workflows/automerge.yml` runs `gh pr merge --auto --squash` on PRs opened/reopened/ready_for_review by the owner or bots.
3. **CD** — self-hosted runner on the Pro (`~/actions-runner-precedent`, label `precedent-pro`, launchd service). App + cloudflared tunnel under launchd (`com.precedent.app`, `com.precedent.tunnel`, KeepAlive). `.github/workflows/deploy.yml` after CI on main: fetch + reset to origin/main, pip install, `launchctl kickstart -k`, health check localhost:3000/api/health + public URL with retries, roll back to the previous commit on failure. The Pro's uncommitted hotfixes are saved to a patch and not wiped before they are merged upstream.
4. **ACS hot-loader** — vendor the runtime (seat protocol + watchdog) from `Pukujan/agent-custom-setup` `modules/coordination/multi-agent-hotload` into `acs/`. The app reloads ACS config/claims on change through a file watcher and `POST /api/acs/reload` (no `uvicorn --reload`). Add tests.
5. **PDD hardening** — fail-closed gates, deterministic tests, rollback on a failed deploy.

## Acceptance criteria
- [ ] `gates` is green on PRs and main
- [ ] A PR by the owner auto squash-merges with no human approval once `gates` passes
- [ ] Deploy runs on the `precedent-pro` runner, and public `/api/health` returns 200
- [ ] A failed health check rolls back
- [ ] ACS claims/config hot-reload without a restart, with tests
- [ ] No secrets printed or committed
