## Summary
- `requirements.txt` is a uv universal lock with `python_full_version` branches for 3.9, 3.10, 3.11 and 3.12+. Dependabot's pip updater re-resolves the file without those branches, so every version PR it opens pins the newest release for every Python and cannot install on the images CI and the Pro use (`networkx==3.7` needs >=3.12, `numpy 2.5` needs >=3.11, `scipy 1.18` needs >=3.11).
- Setting `open-pull-requests-limit: 0` on the pip entry stops version-update PRs while leaving Dependabot security updates enabled. GitHub Actions updates are unchanged.
- AGENTS.md now says how Python dependencies are bumped: edit `requirements.in`, rerun the `uv pip compile` command at the top of `requirements.txt`. The gates job recompiles and diffs the lock, so drift is still caught.

Closing the old PRs did not stop Dependabot from recreating them; this changes the config so it stops opening them at all.
